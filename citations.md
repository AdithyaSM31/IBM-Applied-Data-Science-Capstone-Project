# Project Citations and References

## Methodology and Analysis Notebooks

The following Jupyter Notebooks were developed and utilized for the outcome prediction of the Falcon 9 First Stage Landing, as part of the Applied Data Science Capstone Project.

1.  **Data Collection (API):**
    *   **File:** `jupyter-labs-spacex-data-collection-api.ipynb`
    *   **Description:** Requests to the SpaceX API to collect launch data, performing basic data wrangling and formatting.

2.  **Data Collection (Web Scraping):**
    *   **File:** `jupyter-labs-webscraping.ipynb`
    *   **Description:** Web scraping Falcon 9 historical launch records from Wikipedia.

3.  **Data Wrangling:**
    *   **File:** `labs-jupyter-spacex-Data wrangling.ipynb`
    *   **Description:** Exploratory Data Analysis (EDA) to determine training labels (success/failure) and handle missing values.

4.  **Exploratory Data Analysis (Visualization):**
    *   **File:** `edadataviz.ipynb`
    *   **Description:** Using Matplotlib and Seaborn to visualize relationships between flight number, payload mass, orbit type, and launch success.

5.  **Exploratory Data Analysis (SQL):**
    *   **File:** `jupyter-labs-eda-sql-coursera_sqllite.ipynb`
    *   **Description:** Executing SQL queries against the dataset to derive insights such as total payload mass and success rates by landing outcome.

6.  **Predictive Analysis (Machine Learning):**
    *   **File:** `SpaceX_Machine Learning Prediction_Part_5.ipynb`
    *   **Description:** Building and evaluating classification models (Logistic Regression, SVM, Decision Tree, KNN) to predict landing outcomes.
